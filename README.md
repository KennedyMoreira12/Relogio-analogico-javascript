## ✨ Funcionalidades

- Ponteiros de **hora**, **minuto** e **segundo** sincronizados com a hora real
- Atualização automática a cada segundo (`setInterval`)
- Mostrador analógico com horário de acordo com o fuso do dispositivo

## 🚀 Como executar

Abra o arquivo `index.html` no navegador. O relógio começa a funcionar imediatamente.
